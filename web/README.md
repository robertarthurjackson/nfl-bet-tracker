# NFL Bet Tracker — web

Vite + React 18 + TypeScript SPA for the personal NFL betting tracker. Mobile-first dark UI,
installable as a PWA on an iPhone home screen. Built strictly against `docs/API.md`.

## Commands

```bash
npm install

npm run dev          # dev server on :5173, proxies /api -> http://localhost:8000
npm run dev:mock     # same, but VITE_MOCK=1 swaps in the in-memory mock API
npm run build        # -> web/dist (FastAPI serves this at /)
npm run preview      # serve the production build locally
npm run typecheck    # tsc --noEmit
npm run test         # vitest: mock fixture contract checks + jsdom route smoke test
npm run check        # typecheck + test + build
npm run icons        # regenerate public/*.png from scripts/make-icons.mjs
```

## Mock mode

`VITE_MOCK=1` swaps `src/api/client.ts` (real `fetch` against `/api/...`) for
`src/api/mock.ts` — an in-memory implementation whose fixtures match the contract shapes
exactly. It serves a Week 1 / 2026 slate (CLE @ JAX with JAX around -400 ML and -7.5, plus
five other games) across nine books, and POST/PATCH/DELETE mutate the in-memory state, so
logging a bet, grading it, and moving the bankroll all work end to end without a backend.

`src/api/index.ts` defines the single `Api` interface both implementations satisfy, and
exports the one the app should use. Pages only ever import from `src/api`.

## Layout

```
src/
  api/        types.ts (contract mirror) · client.ts (real) · mock.ts · index.ts (interface + switch)
  components/ Layout · BetSlip · Toast · States · LineChart
  lib/        format.ts · storage.ts · useAsync.ts · settings-context.tsx
  pages/      Board · Opportunities · Bets · Bankroll · Clv · Forecasts · Research · Method · Settings
  styles.css  all styling — CSS variables, no framework
```

## Conventions

- Money `$1,234.50`, percentages to one decimal, probabilities rendered as percentages,
  American odds always signed (`-110`, `+320`).
- Tables scroll horizontally inside `.table-wrap`; the page itself never scrolls sideways.
- Rows at or above the EV threshold are green-tinted; below it they are dimmed.
- Selected week, the board's "only above threshold" toggle, and the alerts min-EV slider
  persist in `localStorage` (all reads/writes wrapped in try/catch).
- Any non-2xx `{ "detail": … }` surfaces as a toast; every page has loading and error states.

## PWA

`vite-plugin-pwa` generates the manifest and service worker (`registerType: 'autoUpdate'`,
standalone display, theme `#0d1117`). Icons in `public/` are generated by
`scripts/make-icons.mjs`, which writes PNGs directly with zlib — no image dependency.
To install on iPhone: open the site in Safari, Share → Add to Home Screen.

## API key

The odds API key lives on the backend, in `api/.env` as `ODDS_API_KEY`. The Settings page
shows whether the server reports it as set (`api_key_set` in `GET /api/settings`).
